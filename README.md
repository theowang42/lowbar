# lowbar

极简每日自重健身 App。打开就知道今天练什么，练完打卡。

- 只需要一根矮单杠（吊着时脚碰得到地也没关系）
- 周一到周六 A/B 交替（A：推 + 腿，B：拉 + 核心），周日休息，每次 15–20 分钟
- 连续 3 次完成某个动作，目标自动 +1；到上限后自动升到下一等级；没完成不降级
- 连续天数打卡，周日不练不算断
- 纯静态网页：零后端、零费用、可离线、可安装成 App，数据只存在你自己的浏览器里

键盘：`空格` 完成今天，`1`–`6` 勾选动作。

## 在 GitHub Pages 上发布

1. 确保代码在 `main` 分支上（根目录有 `index.html`）
2. 打开仓库的 **Settings → Pages**
3. **Build and deployment** 中 **Source** 选择 **Deploy from a branch**
4. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
5. 等一两分钟，页面顶部会出现地址，一般是 `https://<你的用户名>.github.io/lowbar/`

之后每次推送到 `main` 都会自动重新发布。已打开过的设备会先显示旧版本并在后台更新，再打开一次就是新版本。

> 私有仓库使用 Pages 需要付费计划；免费账号请把仓库设为 Public（数据不在仓库里，公开代码没有隐私问题）。

## 安装为 App

先用浏览器打开上面的 Pages 地址，完成一次首次引导。

- **iPhone / iPad（Safari）**：点底部分享按钮 → **添加到主屏幕**
- **Android（Chrome）**：右上角菜单 ⋮ → **安装应用**（或"添加到主屏幕"）
- **电脑（Chrome / Edge）**：地址栏右侧的安装图标 ⊕，或菜单 → **投放、保存和分享 → 将网页作为应用安装**（Edge：**应用 → 将此站点作为应用安装**）
- **Mac（Safari 17+）**：菜单 **文件 → 添加到程序坞**

安装后可离线使用。

## 数据

数据保存在当前浏览器的 localStorage 中，**不同设备、不同浏览器之间不共享**。清除浏览器数据会丢失记录，建议偶尔在设置里 **导出 JSON** 备份；换设备时在新设备上 **导入 JSON**。（v0.2 会加入多设备同步。）

## 开发

没有构建步骤，没有依赖。

```sh
python3 -m http.server 8000   # 然后打开 http://localhost:8000
node --test                   # 需要 Node 22+
```

训练计划在 `plan.js`，规则在 `core.js`，完整设计规范见 [CLAUDE.md](CLAUDE.md)。
